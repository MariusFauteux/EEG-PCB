# EEG acquisition PCB

Portable eight-channel EEG recorder built around the TI ADS1299, for long-term comparison of PEDOT:PSS and Ag/AgCl electrodes. It records to microSD whilst streaming over BLE to a Mac.

**Status (2026-11-08):** Rev C4, Step 7 complete as a schematic bench candidate. There is no PCB layout, no firmware and no physical test. The board is not released for fabrication or for connection to a person.

The schematic sheets are generated by `hardware/scripts/build.py`. Edits made by hand in the KiCad editor are overwritten on the next rebuild, so a schematic change belongs in the scripts.

## Rebuilding and checking

One-time setup from this folder:

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
```

Then regenerate the schematic, export the netlist, run ERC, render the previews and run every check:

```bash
hardware/rebuild.sh
```

The script finds `kicad-cli` on the PATH or in `/Applications/KiCad`; set `KICAD_CLI` to override. The current result is 275 netlist assertions passing, zero ERC errors and passing codec tests. ERC also reports 271 warnings, all of the form "the current configuration does not include the footprint library …". These mean the local KiCad 10 installation has no global footprint-library table yet; KiCad offers to create one on first launch of the GUI. They do not indicate a circuit fault.

## Open items and release gates

Nothing below has been closed by measurement. The Rev B review findings R01–R12 remain formally open; most are now addressed in the schematic but await physical evidence.

| # | Item | Notes |
|---:|---|---|
| 1 | **BIAS stability and protection (Step 8, next)** | Loop not analysed with realistic electrode and cable loads |
| 2 | Deferred Step 4 review | ≈ 11 mV analogue reset release margin, rail-collapse behaviour, restart latch, capacitor qualification |
| 3 | Charger integration | BQ25798 selected but not drawn; J400 is a temporary bench input; pack and connector not chosen |
| 4 | Isolated trigger and photodiode | Reserved in the pin map; no circuit |
| 5 | Shared-REF channel coupling | Modelled ≈ −37.3 dB at 100 Hz; decide reference distribution before electrode comparisons |
| 6 | Powered-off backfeed | ADC input clamps may back-power AVDD from the electrodes; unresolved |
| 7 | Mechanical service interlock | Prevent USB insertion with the electrode harness attached; not designed |
| 8 | BOM and footprints | 301 parts: 32 without footprint, 256 without exact MPN; NINA-B306 needs a custom land pattern |
| 9 | microSD shell pads in KiCad 10 | Stock footprint names shell pads `SH`, schematic symbol uses pin 11; fix before layout (flagged by `validate.py`) |
| 10 | Firmware | No MCU acquisition, BLE or SD firmware; host codec only |
| 11 | Layout, prototype and qualification | Noise, leakage, ESD, endurance, power-loss and safety testing |
